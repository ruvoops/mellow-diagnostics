# mellow 14日間業務診断

mellowの業務負担を14日間記録し、改善ポイントを数値化する静的Webアプリです。

## 起動方法

依存ライブラリはありません。`index.html`を直接開くか、ローカルサーバーで配信します。

```sh
python3 -m http.server 4179
```

その後、ブラウザで `http://127.0.0.1:4179/` を開きます。

## 主な機能

- 日次アンケート入力
- 日本語の音声認識と項目への自動反映
- 直近14日分の集計
- 稼働時間・睡眠時間のグラフ
- 現在の傾向の自動表示
- 記録の編集・削除
- CSV出力
- 印刷・PDF保存

## データの保存

入力データはブラウザの `localStorage` に保存され、外部サーバーへ送信しません。音声ファイルは保存しません。ただし、ブラウザの音声認識機能はブラウザ提供元のサービスを利用する場合があります。

このツールには、顧客名、健康情報、施術中の私的な会話などを入力しないでください。端末変更やブラウザデータ削除の前にCSVを出力してください。

## 対応方針

音声認識は `SpeechRecognition` または `webkitSpeechRecognition` に対応するブラウザで利用できます。未対応ブラウザでは、認識結果欄へ文章を入力し、「文章からフォームへ反映」を利用できます。
